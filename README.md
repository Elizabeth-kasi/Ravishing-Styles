# Ravishing Styles

A simple, responsive fashion and clothing business website built for the New Horizon HTML, CSS and JavaScript individual practical assignment.

## Pages
- Home (`index.html`)
- About (`about.html`)
- Products (`products.html`)
- Contact (`contact.html`)

## Technologies
- HTML5: headings, navigation, sections, images, links and forms
- CSS3: external stylesheet, box model, Flexbox, Grid and media queries
- JavaScript: mobile menu, clothing category filters and contact form validation

## How to run
Open `index.html` in a browser, or run a local static server. No installation is needed.

## Contact form
This is a demonstration form. JavaScript validates the entered fields; it does not send messages to a server.

## Image credits
Fashion images are served from Unsplash. Internet access is needed for them to display.

## Deployment
Publish the repository to Netlify. For this plain HTML project, the publish directory is the repository root (`.`) and no build command is needed.
